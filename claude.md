# Project Instructions

## Package Manager

**IMPORTANT:** This project uses `pnpm` as the package manager.

- Always use `pnpm` commands, never `npm` or `yarn`
- Install dependencies: `pnpm install`
- Add packages: `pnpm add <package-name>`
- Add dev dependencies: `pnpm add -D <package-name>`
- Run scripts: `pnpm <script-name>`
- Remove packages: `pnpm remove <package-name>`

Do not use `npm install`, `npm run`, `yarn add`, or any other package manager commands.
